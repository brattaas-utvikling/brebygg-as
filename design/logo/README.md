# Logo

`original/` er kundens originale vektorlogo (oktober 2026), urørt. Brukes til
trykk, skilt og nye eksporter. Mappen ligger utenfor `public/` og publiseres
ikke på nettsiden.

Nettsiden bruker de ryddede versjonene i `public/images/logo/`:

| Fil | Bruk | Endring fra originalen |
|---|---|---|
| `bre-bygg-logo.svg` | Header (positiv: tekst #231F20, fjell #58595B) | `viewBox` strammet inn til innholdet (73 93 2866 1753), tall avrundet til én desimal |
| `bre-bygg-logo-negativ.svg` | Footer (hvit) | Samme |

Ikonene i `public/` (`favicon.svg`, `favicon.ico`, `favicon-96.png`,
`apple-touch-icon.png`, `icon-192.png`, `icon-512.png`) og delingsbildet
`public/images/og-standard.jpg` er laget fra fjellet i originalen: hvitt på
Green Leaf (#81816B). Fjellet fyller 67 % av bredden på app-ikonene, 78–84 %
på de minste faviconene.
